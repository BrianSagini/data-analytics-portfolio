# Data Sources

## Project 1 — Climate Risk & Business Impact

| Source | Endpoint | Auth | Verified |
|---|---|---|---|
| Open-Meteo Historical Archive | `https://archive-api.open-meteo.com/v1/archive` | None (keyless) | Live GET on 2026-09-12, returned real daily data |
| Open-Meteo Forecast | `https://api.open-meteo.com/v1/forecast` | None | Live GET on 2026-09-12 |
| Open-Meteo Geocoding | `https://geocoding-api.open-meteo.com/v1/search` | None | Live GET on 2026-09-12 |

Licensing: Open-Meteo data is CC-BY-4.0 (attribution required — given here and in the dashboard footer).
Rate limits: free tier allows up to 10,000 calls/day; this pipeline issues ~10/run.

Business exposure fields (`industry`, `annual_revenue_usd`, `asset_value_usd`) in
`climate_risk.locations` are **synthetic**, flagged `is_synthetic_business_data = true`.

## Project 2 — Dark Store Intelligence

| Source | Endpoint | Auth | Verified |
|---|---|---|---|
| UCI "Online Retail II" dataset | `https://archive.ics.uci.edu/static/public/502/online+retail+ii.zip` | None (keyless, direct download) | HTTP 200 confirmed on 2026-09-12 |

Licensing: UCI Machine Learning Repository, CC BY 4.0. ~1M real UK/EU online-retail transactions
(Dec 2009–Dec 2011), no store or inventory dimension by itself.

Store locations, per-store inventory levels, and fulfillment/ROI fields are **synthetic** —
generated by assigning real transactions to a set of synthetic "dark store" fulfillment
locations and layering on synthetic stock levels, clearly flagged `is_synthetic = true`
in the relevant tables. See `docs/methodology_dark_store.md`.

## Project 3 — AI Hiring Bias Detector

Fully **synthetic** recruitment-funnel data — no real applicant data is used or required.
Real anonymized hiring datasets with protected-attribute labels are either not freely
redistributable or carry licensing/ethical constraints incompatible with a public portfolio
repo, so a parameterized synthetic generator was used instead, with a documented, adjustable
bias-injection mechanism so the fairness metrics have something real to detect. See
`docs/methodology_hiring_bias.md` and `projects/03_ai_hiring_bias_detector/pipeline.py`.

## Project 4 — Fraud Pattern Evolution Tracker

Fully **synthetic** transaction data with injected fraud rings (shared devices/IPs/beneficiaries)
for graph analytics — for the same reason as Project 3: real labeled fraud datasets are either
gated (Kaggle account + competition rules) or under NDA in practice. See
`docs/methodology_fraud_pattern.md` and `projects/04_fraud_pattern_evolution/pipeline.py`.

## No API key was required for any of the four projects

No project in this portfolio was blocked on a missing credential. If a future extension needs
one (e.g., a paid weather/insurance API), it should be read from `.env` / an Airflow Connection,
never hardcoded — see `docs/architecture.md`.
